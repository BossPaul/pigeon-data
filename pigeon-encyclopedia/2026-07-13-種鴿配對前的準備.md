# 種鴿配對前的準備 — 驅蟲順序、體能調整、配對時機

## 今日課題

**種鴿配對不是「時間到了關在一起」那麼簡單——前三週的準備決定了一整季的成敗。**

---

## 核心觀念

### 1. 驅蟲順序：先外後內，先殺後補

很多鴿友驅蟲是全部一起上，這是最危險的。正確邏輯是：

**第一週：體外蟲 + 體內蟲**
→ 羽蝨、鴿蠅會讓鴿子煩躁不安，交配品質直接打折
→ 體內蟲（蛔蟲、線蟲、絛蟲）影響營養吸收，身體狀態拉不起來

**第二週：球蟲 + 毛滴蟲（原蟲）**
→ 這兩種原蟲在鴿子疲勞時會爆發，配對前必須壓到最低
→ 等體內蟲藥退乾淨再做，避免肝腎負擔疊加

**第三週：呼吸道 + 整理期**
→ 黴漿菌、衣原體在種鴿舍最容易被忽略
→ 呼吸道乾淨的種鴿，孵蛋時不會打噴嚏汙染蛋殼

**第四週：營養補償 + 體能拉抬**
→ 驅蟲後的肝腎修復期，搭配肝精、電解質、B群
→ 飼料逐步拉高蛋白（15%→18%），為下蛋蓄能

> ⚡ Paul 你現在在用聯華速寧驅體內蟲，方向是對的。但記得：速寧停藥後最少間隔 **3 天**再接原蟲藥，不要連續轟炸。

### 2. 配對時機：不是「時間到了」，是「狀態到了」

種鴿能不能配，看的不是農民曆，是四個指標：

- **羽毛狀態**：主羽換到第幾根？至少要換到第 6-7 根以上才是真換完，不能光看外表亮
- **糞便成條**：驅蟲後的糞便要從稀→軟→成條→乾白頭，才算消化系統回穩
- **胸肌色澤**：胸肌要呈現粉紅色而不是蒼白或暗紫，代表血液循環和攜氧量正常
- **求偶行為**：公鴿開始頻繁咕咕叫、佔巢，母鴿願意蹲下接受——這種「自己要配」的慾望，比強迫配對的受精率高 30% 以上

### 3. 體能調整：長肉不長油

種鴿在配對前最常犯的錯：**餵太營養，養出一身油。**

配對前 3-4 週的飼料策略：

| 階段 | 飼料配法 | 目的 |
|:---:|:--------|:----|
| 驅蟲期 | 清淡料（大麥+稻穀為主，少豆類） | 降低腸道負擔，讓藥效集中 |
| 停藥修復 | 中蛋白（清除料60%+營養料40%） | 修復肝腎，穩定體重 |
| 配對前 1 週 | 高蛋白（營養料60%+豆類20%+種子料20%） | 蓄能產蛋，提升受精率 |
| 配對當下 | 自由取食 | 讓鴿子自己調整食量，別人為干涉 |

## 實戰應用（Paul 現在就能做）

你現在正處在 **驅蟲期 → 停藥修復期** 的交界：

1. **速寧療程結束後**，給 3 天清水 + 微量元素電解質，不餵藥、不加料
2. **觀察糞便**：如果第 3 天還是不成條，再多給 2 天修復期，不急著上下一輪藥
3. **分籠管理**：驅蟲期間公母分開養，讓雙方專心換羽+恢復體力，不要提早合籠消耗精力
4. **根據羽數算種鴿預備量**：如果你的種鴿群約 20-30 對，現在就要確認配對籠數量夠不夠、巢碗清潔消毒了沒

> 💡 **進階提示**：配對前 2 天，早晚各一次光照延長（用日光燈從 12h 拉到 14h），可以刺激生殖軸啟動，加速配對意願。這招對冬季即將進入短日照的種鴿特別有效。
